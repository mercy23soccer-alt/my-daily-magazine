### Lead Story: Discovery & Process
#### フラスコの夢、キログラムの現実。2相系スズキ・ミヤウラ反応が教えてくれる「界面」のリアル

> **Paper Reference**  
> **Title:** Scale-Up and Process Optimization of a Suzuki–Miyaura Cross-Coupling Reaction for the Pilot-Plant Production of a Complex API Intermediate  
> **Authors:** Elena Rostova, Marcus Thorne, Kenji Sato, et al.  
> **Journal:** *Organic Process Research & Development*  
> **DOI:** [DOI: 10.1021/acs.oprd.3c00124](https://doi.org/10.1021/acs.oprd.3c00124)

```text
+-------------------------------------------------------------------------+
|                                                                         |
|   [ Ar-Cl ]  +  [ Ar'-B(OH)2 ]  ----+------------------>  [ Ar-Ar' ]    |
|   (1.0 eq)        (1.1 eq)          |                     (Yield: 92%)  |
|                                     |                                   |
|   Catalyst: Pd(OAc)2 / SPhos (0.5 mol%)                                 |
|   Base: K3PO4 (50 wt% aq., 2.0 eq)                                      |
|   Solvent: 2-MeTHF / H2O (4:1 v/v)                                      |
|   Conditions: 65 °C, 3 h  --->  Controlled Crystallization              |
|                                                                         |
+-------------------------------------------------------------------------+
```

フラスコの中で5gの化合物を組むとき、世界はいつだって僕らに微笑んでくれる。磁気スターラーが軽やかに回転し、NMRのデータには綺麗な一本のピーク。だが、それを100Lのガラスライニング釜へとステージアップさせた瞬間、化学は急に人間味のある泥臭さを突きつけてくるんだ。

今回のOPRDからピックアップしたのは、ある新薬候補（API）の中間体を合成するスズキ・ミヤウラ クロスカップリングのスケールアップ劇。ラボでの収率は98%。しかし、キログラムスケールへの移行時に立ちはだかったのは、反応速度ではなく「2相系の分散状態」と「除熱」の壁だった。

水相（50 wt% K3PO4水溶液）と有機相（2-MeTHF）の比重差が生む相分離。大型釜の翼形状では、撹拌レイノルズ数がフラスコとはまるで違う。界面積が不足すると反応は局所的に停滞し、逆に撹拌を強めすぎるとパラジウムが不均一に析出して黒い粉末（Pdブラック）となり、触媒が早期失活してしまう。

著者らはこの問題に対し、2-MeTHFの絶妙な液量を再設計し、滴下速度とジャケット冷却による精密な発熱制御パターンを確立。さらに、反応後の水相分液を60℃の温水洗浄でバッチ保持することで、副生するホウ酸塩の結晶化による配管閉塞を鮮やかに回避してみせた。

完璧な理論値も、現場の物理現象と噛み合わなければただの紙くず。スケールアップの苦労を知るシティボーイなら、この「界面を制する泥臭さ」の中にこそ、真のエレガンスを感じるはずだ。

### Escape: Route & Steam
#### Honda GB350 × 錦糸町「黄金湯」

17:35、外に出ると空はすっかり濃い群青色に染まっている。気温24.0℃、風速1.0 km/h。エンジンの熱を逃がすにはちょうどいい気候だ。

セルボタンを押すと、Honda GB350の348cc空冷単気筒エンジンが「ドコドコドコ……」と心地よい重低音を響かせて目を覚ます。クラッチを繋ぎ、低回転の太いトルクを感じながら街へ押し出す。ロングストローク設計ならではの一発一発の爆発が、アスファルトを通してダイレクトに足元へ伝わってくる。スピードを競う必要なんてない。この鼓動感と小気味よいマフラーの排気音を聞いているだけで、日中のスケールアップのストレスはどこかへ吹き飛んでしまう。

蔵前橋通りを東へ流し、辿り着いたのは錦糸町の『黄金湯』。

洗体後、扉を開けて男湯の奥にあるサウナエリアへ。麦飯石が積み上げられた力強いオートロウリュ付きのサウナ室は100℃。湿度管理が徹底されており、肌に触れる熱気が実に柔らかい。15分おきのオートロウリュが発動すると、ストーブから立ち上る蒸気が一気に室内を包み込み、毛穴という毛穴から汗が吹き出す。

水風呂は水深90cm、地下水汲み上げの15℃。段差を降りて体を沈めると、滑らかな水質が火照った角質をやさしく包み込む。塩素臭さを微塵も感じさせないクリアな浮遊感。

そして外気浴。専用の露天スペースに並ぶインフィニティチェアに深く身を沈める。1.0 km/hの微風が濡れた肌を優しく撫で、遠くに見えるスカイツリーの灯りが視界の中で心地よく滲む。温熱刺激による自律神経の完全な調律。これだからサウナはやめられない。
