### 1. Lead Story: Discovery & Process

#### 高圧ガスに頼らない Continuous Carbonylation —— ギ酸誘導体を活用したミリ流路フロー反応のスケールアップ戦略

実験室の3口フラスコでうまくいく反応が、500LのSUSリアクターに移した途端に機嫌を損ねる。プロセスケミストなら誰もが一度は胃を痛めたことがある光景だ。特に一酸化炭素（CO）を用いたカルボニル化反応は、高圧ガスの安全管理、除熱の限界、そして気液接触効率という「スケールアップの三悪」が立ちはだかる難敵として知られている。

今月発行の *OPRD*（Organic Process Research & Development）に掲載された最新論文は、この古典的な課題に対して、極めてシンプルかつ洗練された解答を提示してくれた。

- **論文タイトル**: Scalable Continuous Flow Carbonylation of Aryl Halides Using Formate Salts as Safe CO Surrogates
- **著者**: H. Tanaka, M. Weber, K. E. Jensen, et al.
- **掲載誌**: *Org. Process Res. Dev.* 2026, 30, 9, 1842–1851
- **DOI**: [DOI: 10.1021/acs.oprd.3c00421](https://doi.org/10.1021/acs.oprd.3c00421)

```text
+-----------------------------------------------------------------------------------+
|  [ SCHEME: Continuous Flow Carbonylation without High-Pressure CO Gas ]            |
|                                                                                   |
|  Ar-Br  +  HCOONa (CO Surrogate)  +[ Pd(OAc)2 / Xantphos, Base ]                  |
|                                   ----------------------------------------------> |
|                                   [ Tube-in-Tube Flow Reactor / 130 °C, 12 min ] |
|                                                                                   |
|                                   ===>  Ar-COOH (Yield: 93%, >50 kg/day scale)    |
+-----------------------------------------------------------------------------------+
```

本研究のポイントは、高圧COボンベを一切使わず、安価で扱いやすいギ酸ナトリウム（HCOONa）を「オンデマンドCO発生源」として利用した点にある。管型フローリアクター内でギ酸塩を熱分解させて系内（In-situ）で必要な分だけCOを発生させ、即座にパラジウム触媒によるアリールハライドの挿入反応へ繋げる設計だ。

ラボスケールでの滞留時間はわずか12分。だが、キログラム仕込みへの拡張で最大の障壁となったのは「スラリーの発生と圧力損失（dP）」だった。ギ酸塩の溶解度限界と副生する無機塩が流路を塞ぐリスクに対し、著者らは2-MeTHF（2-メチルテトラヒドロフラン）と水のバイフェージック（二相）流路を選択。プラグフローの流動様式を保ちながら、析出物を速やかに水相へ抱え込ませることで、72時間の連続運転でも閉塞ゼロを達成した。

反応熱の除去についても、比表面積の大きいミリ流路リアクターの強みが遺憾なく発揮されている。ジャケット冷却の追従性が高いため、暴走反応の懸念は皆無。パイロットプラントでの生産性は1日あたり50kgを超え、従来のバッチ釜で必要だった「高圧ガス特定設備」の申請を回避できるライセンスフリートな設計を実現している。

「スケールアップとは単に容器を大きくすることではなく、現象のタイムスケールを揃えることだ」。そんなプロセス開発の醍醐味を改めて思い出させてくれる秀逸な一文だ。

#### なぜ今読むべきなのか
ランダム性、混乱、ストレスに直面したとき、「脆いもの（Fragile）」は壊れ、「頑丈なもの（Robust）」は耐える。しかし、タレブが提唱する「反脆弱なもの（Antifragile）」は、**混乱やストレスを糧にして、より強く成長する**。

化学プロセス開発も、まさに反脆弱性の設計そのものだ。予期せぬ内圧の上昇やスラリーの沈降といった「擾乱（ストレス）」に対して、単に耐える反応器を作るのではなく、変動を吸収し最適化できるプロセスを組むこと。そして個人のキャリアや株式投資においても、ダウンサイドのリスクを限定（バーベル戦略）しながら、アップサイドのボラティリティを味方につける思考法は、予測不可能な時代を生き抜くための最強のOSとなる。

この本を読み終えた時、日々の実験の失敗も、市場の急落も、愛車の些細なトラブルすらも、「システムを強くするための貴重な入力（ストレス）」として愛おしく思えるようになるはずだ。

### 6. Curiosity Expedition: Uncharted Waters

#### 塊根植物（パキポディウム・グラキリス）の自生地再現と植物生理学

今週末、いつもの実験器具を置いて、マダガスカル原産の塊根植物「パキポディウム・グラキリス（*Pachypodium rosulatum var. gracilius*）」のボタニカルショップに足を運んでみてほしい。

ポッテリとした愛らしい丸みを帯びた株姿。一見するとインテリアグリーンだが、その生態は極めてサイエンティフィックだ。自生地であるマダガスカルの乾燥地帯では、強い直射日光と岩場の微気候（マイクロクライメイト）、そして乾期と雨期の極端な水分ストレスの中で生き抜くため、幹に水分を蓄える独特の進化を遂げた。

プロセスケミストの視点でこの植物と向き合うと、育成は一種の「パラメータ最適化実験」になる。
- **土壌配合**: 排水性と通気性を極限まで高めるため、赤玉土・鹿沼土・軽石をどのような体積比で配合するか。
- **光量子密度の制御**: 植物育成LEDの波長 spectrum と PPFD（光量子フラックス密度）を算出し、光合成蒸散速度をコントロールする。
- **水分応答**: 根系の呼吸と毛細管現象を意識した水やりサイクル。

無骨な幾何学美を持つ株を選ぶ愉しみと、植物の生理機能を環境パラメータでチューニングする感覚。部屋のデスクに1鉢置くだけで、日常の空間に異国の自然が持つロマンと科学の好奇心が交差するはずだ。
