### 1. Lead Story: Discovery & Process

微かに湿り気を含んだ秋の風が吹く今夜、ぼくらが注目したいのは*OPRD (Organic Process Research & Development)*に送られた、スケールアップの課題を極めてエレガントに解決した連続流（フロー）合成の報告だ。

バッチ釜で200Lの反応を回すとき、ぼくらを一番憂鬱にさせるのは熱移動の遅れと、不均一系試薬の沈降による局所的な過熱なんだ。特に発熱の大きいC–Nクロスコーカップリングにおいて、スケールアップ時の副生成物（デアロ化）の増大は永遠の課題だった。

筆者らはパラジウム触媒と塩基の懸濁液を詰めた「パックド・ベッド・リアクター（Packed-Bed Reactor）」を最適化し、滞留時間わずか3分でキログラムスケールの変換を達成してみせた。

```
+-----------------------------------------------------------------------+
|                             【SCHEME】                                |
|                                                                       |
|   Ar-Cl   +   R-NH2   ----------------------------->   Ar-NH-R        |
|  (1.0 eq)    (1.2 eq)    [ Cat: Pd/XPhos G4 (0.05 mol%) ]  (Yield: 94%)|
|                          [ Medium: CPME / tBuOH (4:1)   ]             |
|                          [ Temp: 110 °C, BPR: 0.5 MPa   ]             |
|                          [ Flow Rate: 50 mL/min         ]             |
|                                                                       |
+-----------------------------------------------------------------------+
```

このプロセスの美しさは、溶媒にCPME（シクロペンチルメチルエーテル）をチョイスした点にある。THFよりも沸点が高く、水との分液性がすこぶる良い。背圧弁（BPR）で0.5 MPaまで加圧することで、溶媒の沸点を超えた110℃での超高速反応を実現しているんだ。

実験室のナスフラスコで上手くいった反応を、そのままデシリットル、リットルへと引き伸ばすとき、ぼくらは「スケール」という魔物に出会う。だが、流路（チャネル）の幅を一定に保ったままラインを並列化する「ナンバリングアップ」の発想を持てば、熱伝導の計算に頭を抱える必要はなくなる。ポンプの拍動を感じながら、送液チューブの中を無駄なく生成物が流れていく様を眺めるのは、プロセスエンジニアだけの密かな快楽だよね。

### 3. Escape: Route & Steam

17時30分、ラボのドラフトのシャッターを降ろし、ガレージに向かう。愛車の空冷2気筒エンジンに火を入れると、ドコドコと重厚な鼓動が足元から伝わってくる。

今夜の風速は1.8 km/h。ほとんど無風だ。79%の湿度がバブアーのジャケットに微かな湿り気を与え、空冷エンジンの冷却フィンの間を、温かい湿った空気が滑り落ちていくのを感じる。シリンダーから立ち上る熱気とオイルの匂い。この「エンジンの存在」をダイレクトに身体で受け止める感覚こそ、ぼくらがバイクを降りられない理由なんだ。

街の灯りがひとつ、またひとつと点灯するバイパスを抜け、お気に入りのサウナ施設へ滑り込む。

今日の湿度なら、サウナ室は90℃前後のボナサウナ（足元から温風が出るタイプ）が正解だ。じっくりと12分。汗が皮膚の表面を覆い、心拍数が整ったところで、15℃の深めの水風呂に身を沈める。バイブラ（泡）のない静かな水面が、火照った身体に「羽衣」を形成していく。

そして外気浴。24.2℃の外気と無風の条件は、実はととのいにおいて最強のスペックなんだ。風がないから、皮膚の表面から熱が奪われすぎない。ととのい椅子に深く腰掛け、目を閉じる。肌に触れる空気に境界線がなくなり、自分が今、街の空気そのものに溶け込んでいくような感覚。これだから、平日のエスケープはやめられない。
